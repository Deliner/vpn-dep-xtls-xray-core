# Каталог команд

Применяй [общий процесс](../refactor/SKILL.md). Корневой `justfile` — точка входа;
определения находятся в `ops/tasks/` и сгруппированы по назначению. Каждый `.just`
обязан быть достижим из корня через обязательные literal imports.

При цикле imports выдели общие рецепты в нижнюю предметную группу либо объедини одну
ответственность. Если синтаксическая ошибка мешает запустить сам `just`, прочитай этот
файл напрямую и восстанови каталог; не создавай обходной runner или optional import.

Для новой операции сначала найди существующий рецепт. Добавь его в предметную группу,
дай понятное имя и описание; подключи новый файл импортом. Не дублируй shell-команды
в CI, Makefile и README. CI вызывает те же `just` рецепты, что разработчик.

Операции установки и deploy должны быть явными рецептами с аргументами, не зависимостями
`check`, `build` или `bootstrap`. Передавай пользовательские аргументы через позиционные
параметры shell, а не интерполяцию в исполняемый код. Bootstrap toolchain — единственная
команда, которую можно вызвать напрямую до появления `just`.

Проверь `just --list`, `just --dry-run <recipe>` и запуск из вложенного каталога.
Заверши `just check`; orphan-файл или отсутствующий импорт должны давать ошибку.
