# Циклы файлов

Применяй [общий процесс](../refactor/SKILL.md). Для каждого ребра выведенного цикла
найди конкретное объявление и его использование: учитываются функции, типы, методы,
поля и константы через `go/types`, а не совпадения текста.

Определи владельца общей модели. Перенеси её в подходящий нижний слой, отдели политику
от механизма или объедини объявления, которые составляют одну ответственность.
Интерфейс вводи там, где потребитель действительно нуждается в независимом контракте.

Не заменяй прямую зависимость reflection, глобальным callback, runtime registry или
строковым поиском ради обхода графа. Не переименовывай файл без изменения владения.
Проверь и production, и test-варианты на всех поддерживаемых платформах: `just check`.
