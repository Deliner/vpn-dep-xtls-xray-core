# Циклы импортов пакетов

Применяй [общий процесс](../refactor/SKILL.md). Пройди всю цепочку импортов из сообщения
компилятора. Назови контракт, который каждой стороне действительно нужен.

Если пакеты — одна ответственность, объедини их осмысленно. Иначе отдели общий
контракт в нижний слой или размести интерфейс у потребителя; реализация не должна
импортировать сборку приложения. Тестовый код может требовать внешнего `_test` пакета.

Не создавай универсальный `common` со всем содержимым и не заменяй импорт глобальным
регистратором. Проверь граф файлов и родительских каталогов после исправления:
устранение одного compiler error не доказывает корректную архитектуру. `just check`.
