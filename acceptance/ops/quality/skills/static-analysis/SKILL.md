# Компиляция и статический анализ

Прочитай [общий процесс](../refactor/SKILL.md) и исходную диагностику. Отличи дефект
кода от недоступного toolchain, зависимости или платформы. Для окружения используй
`just bootstrap` и `just doctor`; версии закреплены в проекте.

Исправляй причину: контракт типов, lifetime ресурса, неверный format string, потерянную
ошибку или несогласованность build tags. Не добавляй `nolint`, пустой обработчик ошибки,
небезопасное приведение или исключение платформы ради успешного запуска.

Для Bash syntax проверь кавычки, границы блоков и передачу аргументов. Не заменяй
безопасные позиционные параметры на `eval` или интерполяцию пользовательского текста.

При import cycle применяй skill `package-dependencies`. После минимального корректного
изменения выполни соответствующие тесты и `just check`. Сбой внешней загрузки не должен
превращаться в успешную проверку или запуск непроверенного артефакта.
