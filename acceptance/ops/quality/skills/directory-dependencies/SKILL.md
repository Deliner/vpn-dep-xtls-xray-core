# Циклы директорий

Применяй [общий процесс](../refactor/SKILL.md). Линтер объединяет импорты по каждому
уровню пути. Даже ацикличные пакеты `a/one → b/two` и `b/one → a/two` создают `a ↔ b`.

Восстанови смысл групп и разрешённое направление зависимостей. В этом проекте core
содержит общие контракты; platform — операции ОС; runtime — конфиги движка; node —
установку; control — работу с топологией и развёртыванием; quality — проверки разработки.

Проверь, не оказался потребитель в каталоге поставщика и не обращается ли механизм
к верхнеуровневой политике. Раздели ответственность или вынеси общий контракт ниже.
Не меняй глубину пути и названия только для исчезновения цикла из отчёта.

Обнови описание архитектуры и импортирующие стороны, затем выполни `just check`.
