# Ссылки документации

Прочитай [общий процесс](../refactor/SKILL.md), документ с ошибкой и предполагаемую цель.
Определи, переехал ли материал, изменилось ли его назначение или ссылка была ошибочной.
Выбирай канонический документ по смыслу; путь вычисляется относительно файла со ссылкой.

Обнови связанные оглавления и инструкции. Не создавай пустую заглушку по старому пути,
не дублируй содержание и не удаляй полезную ссылку только ради прохождения проверки.
При ошибке чтения сначала проверь существование и доступность файла.

Архивные снимки исследования сохраняются побайтно. Исправляй актуальные указатели на
них, не переписывая исторический текст. Перенос путей не обновляет дату исследования
и не подтверждает прежние выводы заново. Проверка локальных ссылок не проверяет внешние
URL и Markdown anchors.

Если изменены исследовательские документы, выполни `just research-inventory`, затем
`just docs-check` и `just check`. Объясни, какой документ теперь является владельцем темы.
